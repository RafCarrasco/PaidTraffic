# Contexto

OfferLab apoia pesquisa legítima de ofertas digitais e Direct Response, inicialmente para Portugal. Objetivo comercial: primeira venda com controle de custos; objetivo técnico inicial: pipeline utilizável para pesquisar 20 ofertas candidatas. ChatGPT apoia estratégia, Codex engenharia, Claude revisão comercial. O usuário aprova decisões financeiras e publicação de campanhas.

Restrições: não copiar produtos/criativos protegidos, não inventar vendas, não acessar dados privados ou contornar proteções, não usar credenciais de terceiros, não executar chamadas pagas de IA. Nada publica anúncios ou contrata serviços automaticamente.

Escopo atualizado: automação e relatórios antes de interface visual e cadastro manual. SQLite e Python; Firebase, Flutter e SaaS ficam para avaliação futura de custo/benefício.
